# Yellow lightning Storm candidates

Twenty PixelLab Create Object candidates, generated using the accepted previous Storm sprites as style references. Original PNG dimensions and pixels are preserved, all backgrounds are transparent. No runtime assets are replaced or wired. Objects remain in PixelLab review.

`yellow-lightning-all-variants.png` has five columns and four rows of 128x128 cells. The first three rows contain Guard, Bee, Golem, Eye, Archer variants 1, 2, 3. The final row contains Guard 4 and Archon variants 1 through 4. Each native sprite is centered in its cell. No labels are drawn into the transparent sheet.
