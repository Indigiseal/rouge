# Storm Create Object candidates

Suggested six-sprite lineup from PixelLab `create-1-direction-object`. Regular sprites retain their generated 70x70 canvas; boss retains 110x110. All PNGs have transparent backgrounds. No scaling, recoloring or painting was applied to the PNGs. These are review candidates and are not wired into the game.

Full alternatives and previews: `output/art-concepts/storm-objects-v2/`. `generation.json` records prompts, style references, PixelLab object IDs and selected indices. The original objects remain in PixelLab review status so the user can select their preferred variants.
