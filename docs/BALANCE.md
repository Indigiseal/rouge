# Balance (pure runs)

Базовый баланс строится на **чистых забегах**: без амулетов и без мета-прогрессии
(sim preset `balance`). Амулеты и мета — поверх этой базы, отдельными документами,
когда дойдём до них. Открытые дизайны — `OPEN-QUESTIONS.md`. Механики — `MECHANICS.md`.

## Цели акта 1

| Метрика | Цель |
|---------|------|
| Дошли до F15 | **~50%** |
| Победа над боссом F15 (от дошедших) | **~20%** |
| Прошли акт 1 (F16+) | **~10%** |

Act 2/3 gates — TBD после стабилизации акта 1 / кривой reach.

Последняя сверка (3000 runs, `v3-pure`, rogue/Thornwake): reach **53.7%**,
clear **21.8%**, act1 pass **11.7%**. Кросс-проверка ростеров (rogue, 3000 runs):
Thornwake 52.0 / 21.9 / 11.4, Silkdeep 49.7 / 20.6 / 10.2, Tollroad 56.4 / 21.6 / 12.2.

**Оба класса в целях** (n=6000): воин **57.4 / 18.3 / 10.5**, рога
**52.7 / 22.2 / 11.7**. Воина вытащили две правки: удвоение прочности chain/plate
(reach 43.7 → 51.8) и крит на любом типе оружия (clear 9.7 → 18.3). Подробности и
шесть отвергнутых гипотез — в `OPEN-QUESTIONS.md`.

Замеры мельче **±2 pp по clear при n=3000 — это шум**, перемеривать на n=6000.

**Полное дерево талантов** (`--meta --talents max --amulets`, 3000 runs):
reach F15 **92.6%**, F30 **47.9%**, F45 (победа) **33.1%**. Цель полного дерева
~30% win — см. `OPEN-QUESTIONS.md`. Оба класса сведены: Shadow 32%, Iron 34%
(было 43% и 16%).

**Лавина мета × амулеты.** По отдельности полное дерево даёт 0.4% побед,
амулеты без меты — 4.4%; вместе было 43%. Источники не складываются, а
перемножаются: мета проносит через акт 1 с целыми ресурсами → длинный ран даёт
больше офферов → ещё более длинный ран. Ретюн деревьев сбил вершину до 31.7%,
но сама петля обратной связи остаётся открытым вопросом.

## Ворота актов

Финал акта — единственная настоящая стена акта. С полным китом (мета + амулеты)
ворота убивают долю дошедших до них:

| Ворота | Босс | Убивает |
|--------|------|---------|
| F15 | tier 1 (81–89 HP / 11–12 ATK) | ~39% |
| F30 | tier 2 (162–178 HP / 17 ATK) | ~26% |
| F45 | Ancient Cerberus (272 HP / 28 ATK) | ~20% |

До ретюна F45 убивал **1.2%** — финал был самым мягким местом игры. Рядовые
этажи акта 2 при этом убивают 0.2–1.0% каждый: акт держится на воротах, не на трэше.

## Depth scaling (`src/content/balance/DepthScaling.js`)

Плоский бонус тихо умирает по ходу рана: с F1 до F45 ATK врагов растёт ×2.4,
плотность ×1.5, а «+15 HP в начале этажа» платит всё те же 15. Замер сохранения
ценности в акте 3 относительно акта 1:

| Бонус | Сохранение |
|-------|-----------|
| Плоский реген (+15 HP) | **0%** |
| Dragon Claw (+15% урона) | 3% |
| Philosopher's Stone (+20 HP, +8 flat) | 8% |
| Greater Evasion (20% dodge) | 24% |
| Greater Protection (−30% урона) | **32%** |

Правило: бонус привязывается **к глубине, а не к стеку**. Стек-зависимый рост
компаундится со всем уже собранным и кормит лавину мета × амулеты; depth-рост
делает поздний подбор осмысленным без этой петли. `fromFloor` удерживает выплату
на базе до нужного этажа — так гемы растут только с акта 2, и акт 1 не смещается
как побочный эффект.

Переведены: реген-амулеты (`currentCatalog.js`) и урон гемов
(`GEM_STACK_DAMAGE` + `GEM_DEPTH_PER_FLOOR` в `cards/gems.js`; таблица
`[3,4,5,6,7]` раньше дублировалась в 5 местах — 2 в `src`, 3 в симе).

## Где крутить (только реальные числа)

1. Враги / боссы — `CardDataGenerator.enemyData` / `bossData`
2. Веса лута на этаже — `floorWeights` + `balanceCardWeights`
3. Оружие — `src/content/cards/weapons.js` (`WEAPONS` статы, `WEAPON_SPAWN_MIN_FLOOR` лут)
   Броня — `src/content/cards/armor.js` (`ARMORS` + `ARMOR_SPAWN_MIN_FLOOR`)
4. Плотность врагов — `minEnemyRatioForFloor` в board systems
5. Старт — `CharacterClasses.startingWeapons` (только type+rarity), HP `PLAYER_START_HP` в `GameState.js`
   Карточки стартового оружия собираются через `createWeaponCardData` / `buildStartingWeaponCards`

Множителей-knobs нет.

## Как мерить

```bash
npm run sim:stats-db-balance -- 2000 my-label
```

Gate SQL:

```bash
node --input-type=module -e "
import Database from 'better-sqlite3';
const db = new Database('sim/db/stats.sqlite');
const b = db.prepare('SELECT id FROM sim_batches WHERE label=?').get('my-label');
const r = db.prepare('SELECT COUNT(*) n FROM sim_runs WHERE batch_id=?').get(b.id);
for (const f of [15, 30, 45]) {
  const reach = db.prepare('SELECT COUNT(*) n FROM sim_runs WHERE batch_id=? AND reached_floor>=?').get(b.id, f);
  const died = db.prepare('SELECT COUNT(*) n FROM sim_runs WHERE batch_id=? AND reached_floor=? AND won=0').get(b.id, f);
  console.log('F'+f, 'reach', (100*reach.n/r.n).toFixed(1)+'%',
    'clear', (100*(1-died.n/reach.n)).toFixed(1)+'%');
}
"
```

Дашборд / Grafana: `npm run sim:dashboard`, `npm run sim:grafana`.

## Enemy power: bands + archetypes (design SoT)

Целевая модель статов обычных врагов.

**Дизайн:** ран — 3 акта по 15 этажей, по одной локации на акт, выбор из трёх
(всего 9 локаций). Локация задаёт ростер, этаж — силу. Подробно:
`docs/MECHANICS.md` → Run structure, `docs/narrative/Locations/Locations Index.md`.

**Статус кода:** bands + archetypes; ростеры **Thornwake** и **Silkdeep**
(`src/content/months/<id>/enemies/`). Выбора локаций ещё нет — в билде ротация
первых `MONTH_ROTATION_LENGTH` месяцев (`calendar.js`). Остальные месяцы
календаря пока без ростера → legacy `tiers[]` если когда-то выпадут.

### Принцип

| Слой | Что задаёт | Где числа |
|------|------------|-----------|
| **Identity** | имя, спрайт, role, feature (без цифр силы) | контент локации / тип врага |
| **Band** | полка HP/ATK от этажа (дня) | таблица ниже |
| **Archetype** | множители формы (skirmisher / bruiser / …) | таблица ниже |

Локация выбирает *кого* спаунить. Этаж выбирает *насколько сильный* бэнд.
Один и тот же Wolf в акте 1 и акте 3 отличается бэндом, не отдельной таблицей.

Из этого следует ключевое требование к балансу: **все три локации акта должны
быть равны по сложности**. Выбор дороги — это тон и ростер, а не уровень
трудности; true path не должен быть ни легче, ни тяжелее соседей по акту.

Боссы локации — **отдельный boss-band по акту** (не эта таблица). Elite mini-boss
как сейчас: ×1.3 HP/ATK поверх обычных статов.

### Power bands (skirmisher = ×1.0)

Бэнды A–C откалиброваны по **среднему** врагу старого ростера, не по Скелету.
Первая версия брала Скелета за ×1.0, но он был самым сильным мобом акта 1 —
средний ATK этажей F5–F10 вырос на 64–83%, и reach F15 упал с 53.8% до 19.6%.
Ослабление A–C компенсировано боссами акта 1 (HP ×1.35, ATK +1): без этого
`clear F15` не опускался ниже 43% ни в одной конфигурации бэндов.

D–G сняты со старого Скелета и пока не пересматривались. F15 **не** отдельный моб-бамп:
полка C до конца акта, финал у босса. Mid-act 2 даёт ATK-ступень (E). Mid-act 3 — лёгкий хвост (G).

| Band | Floors | HP | ATK | Заметка |
|------|--------|----|-----|---------|
| A | 1–4 | 8 | 4 | старт |
| B | 5–9 | 10 | 5 | |
| C | 10–15 | 12 | 7 | полка до босса акта 1 |
| D | 16–22 | 17 | 8 | стык акта 2; ≈ skeleton F16 HP |
| E | 23–30 | 17 | 10 | mid-act 2: рост ATK |
| F | 31–37 | 20 | 11 | стык акта 3; ≈ skeleton F31 |
| G | 38–45 | 22 | 12 | хвост акта 3 |

Спайки осознанные: **F16** (A→D по смыслу акта) и **F31**. Внутри акта — плоские полки.

`stats = band(floor) × archetypeBias` (округление при имплементации: `ceil` для HP/ATK после множителя, clamp ≥1).

### Archetypes

| Archetype | HP | ATK | Типичные роли |
|-----------|----|-----|----------------|
| skirmisher | ×1.0 | ×1.0 | обычный melee (Wolf, Skeleton) |
| bruiser | ×1.25 | ×0.95 | толстые ближники |
| swarm | ×0.75 | ×0.9 | мелкие / кучи |
| artillery | ×0.7 | ×1.15 | ranged (лучники) |

Враги с сильной feature (poison, evade): можно чуть снизить bias (например HP ×0.9),
сила в правиле, не в голых цифрах паспорта.

### Locked feature (exception)

- **Wolf:** +1 ATK per other revealed living Wolf on the board (situational; not on the passport band).

### Feature без цифр силы

В описании/identity — правило («рядом с союзником-волком бьёт дважды»), не «+3 ATK».
Если правилу нужны числа — из бэнда или фиксированных дизайн-констант (1 DEF, 1 hit),
не из уникальной HP-таблицы типа.

### Имплементация (когда дойдём)

1. Один `POWER_BANDS` + `ARCHETYPES` в content.
2. Тип врага: `archetype` + abilities/feature; без своих `tiers[]` HP/ATK.
3. `createTieredEnemy` читает band(floor) × archetype.
4. Прогнать act1 sim против текущих целей reach/clear.
