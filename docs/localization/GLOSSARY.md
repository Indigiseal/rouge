# Translation glossary

The words a translator must keep the same everywhere. If a card says one word and
the tutorial says another, the player thinks they are two different rules.

Every value below is what the game shows today (`src/i18n/i18n.js`). When a word
changes, change it here and everywhere in the language at the same time.

Languages: English (en), Spanish (es), French (fr), Russian (ru), German (de),
Simplified Chinese (zh), Japanese (ja), Korean (ko), Brazilian Portuguese (pt). Chinese, Japanese, Korean
and Portuguese cover everything
except event stories, which stay English until the stories are finished.

## What kind of game this is

A roguelite **card crawler**, not a deckbuilder. There is no deck, no hand to
draw, no Exhaust or Retain. Cards lie face-down on a board; you flip them, fight
with weapon cards, wear armor cards, and carry cards in a small bag. Weapons and
armor wear down one pip at a time and break when the pips run out. Two matching
cards merge into a stronger one.

The rarity is joined to the item name by code (`translateItemName`, rules in
`GENDERED_RARITY` in `i18n.js`). The table above gives the masculine form.

- es, fr, pt: rarity after the noun, agreeing with it: Espada rara, Épée rare,
  Machado Raro (pt names are title case).
- de, ru: rarity first, agreeing with it (ru has a neuter for the spear: Редкое копьё): Seltenes Schwert, Legendäre
  Plattenrüstung, Редкая латная броня.
- ko: rarity first with a space (희귀 단검); zh, ja: no space (稀有匕首, レアダガー).
- A new weapon or armor type needs its gender added to `GENDERED_RARITY`.

## Names

- **Act names stay English** in every language: Thornwake, Silkdeep, Tollroad,
  Boneflood, Brassfair, Duskhold, Mirrorwane, Spherefall, Starfold, Veilbleed,
  Mireturn, Ashhowl, Sandreach, Frosthollow, Stormhatch. The place line under
  each one ("The Briar March") is translated.
- **Enemies, bosses, items and amulets are translated.** Proper-sounding item
  names keep their joke or image, not their literal words.
- **Mimic** is the chest monster, not "mimicry". In German it stays "Mimic"
  (the German word *Mimik* means facial expression).

## Voice and register

- The English is **dry and situation-first**: what is in the room, then what
  happens. Short sentences, understatement, no fantasy-narrator flourish. Keep
  that in every language. The full brief for story text is in
  `CHATGPT-BRIEF.md`.
- **Spanish:** informal tú. No vosotros, so it works for Spain and Latin America.
- **French:** formal vous. French spacing before `: ; ! ?` and `%`.
- **Russian:** currently mixed. Menus and the tutorial use ты, item
  descriptions and events use вы. Still to be decided which one wins.
- **German:** informal du everywhere.
- **Chinese:** plain, neutral 你. No plural, so `.one/.few/.many` keys match.
- **Japanese:** polite form (〜してください) in menus, the tutorial and
  confirmations; short plain form in combat pop-ups (毒を受けた！).
- **Portuguese (Brazil):** informal você. Decimals take a comma (x1,5).
- **Korean:** polite 해요체 in menus and the tutorial (뒤집으세요); short noun
  forms in combat pop-ups (중독!). Particles after a name use the paired form,
  을(를) and 이(가), because the name is filled in at run time.

## Technical rules

- Keep every `{placeholder}` exactly as written. `npm run test:i18n` fails if one
  is missing or renamed.
- Keep `\n` line breaks where the English has them; they are laid out by hand.
- Quotes: use the straight `"` pair in es/fr/ru/de. The fonts do not carry German
  low quotes („). Chinese and Japanese use their own quotes (“” and 「」); Korean uses the straight pair.
- German, French and Spanish run about 30% longer than English. Prefer the
  shorter word on buttons and tooltips; labels shrink to fit but only so far.
- Adding new characters (any new Chinese, Japanese or Korean text) needs a font rebuild:
  `python tools/build-ui-fonts.py`, then `node tools/audit-font-coverage.mjs`.

## Where the text lives

All in `src/i18n/i18n.js`:

- `STRINGS[lang]`: UI text, by key (`ui.shop.title`).
- `GERMAN_STRINGS`, `CHINESE_STRINGS`, `JAPANESE_STRINGS`, `KOREAN_STRINGS`, `PORTUGUESE_STRINGS`: those languages
  kept whole, so one native reader can review each in one sitting.
- `EXACT_NAME_TRANSLATIONS`, `DESCRIPTION_TRANSLATIONS`,
  `EVENT_NARRATIVE_TRANSLATIONS`, `EVENT_TITLE_TRANSLATIONS`: keyed by the
  English text itself.
- `RARITY_`, `WEAPON_`, `ARMOR_`, `GEM_EFFECT_TRANSLATIONS`: the parts item names
  are built from.

Checks: `npm run test:i18n` (every key, every placeholder) and
`npm run audit:l10n` (content text that no table translates).
