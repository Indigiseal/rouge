# Palm slam animation study

Created with the built-in image generation tool; converted to GIF with FFmpeg. Study/reference files only.

Prompt: A new pixel-art sprite-sheet study of a giant violet iron-and-brass ogre gauntlet performing a downward palm slam on stone. Twelve equally sized panels in a 4-column by 3-row grid. Fixed camera, impact point and background. Frames: relaxed pose, opening fingers, raised anticipation, peak windup, fast descent, compressed palm impact, pressure hold/dust ring, release, rebound, soft settling, recovery, relaxed pose. Crisp pixels; no text or grid borders.

The generated panels have some drawing variation; study the action and timing rather than treating this as a production-ready game sprite.
