# Mirrorwane

> [!info] Location — Act 3 (wrong road)
> A palace of glass. You can finish a run here. The Magus is not in the glass. See [[The True Path]].

The country of reflections, doubles, and wrong versions of the familiar. The world looks almost right — and is dangerous for exactly that reason.

## Theme

False familiarity — doubles, wells, and almost-correct rooms
