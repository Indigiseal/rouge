# Music Box Chain

[[Event Sequences|Event Sequence]]. Optional any-location lane (not required for the macro-plot). Tone leans [[Brassfair]]; nest/egg beats keep Stormhatch rooms. None of the beats are location-gated.

## Sequence

1. [[The Broken Music Box]] — opener
2. [[Monster Bird Nest]] — timed nest raid (cog / egg)
3. [[Goblin Engineer]] — repair (hidden if the box exploded)
4. [[The Egg Hatches]] — companion (if egg taken)

## Design rule

These are global sequence events. Never soft-lock the lane because the player picked another location. If the opener explodes, later rooms still appear, but cog and repair choices close.
