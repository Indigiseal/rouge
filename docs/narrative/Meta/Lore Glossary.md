# Lore Glossary

| Term | Meaning |
|---|---|
| **Second Moon** | A magical sphere orbiting the ordinary moon. Broken sky; law that pools in the nine locations. See [[The Second Moon]]. |
| **Turn** | Folk word for a fifteen-day crossing of one location. Not a rotating global month. See [[The Calendar]]. |
| **True Path** | Tollroad → Brassfair → Starfold. Wrong roads still advance the act. See [[The True Path]]. |
| **Location** | One country of the Path. Nine in all, three per act. See [[Locations Index]]. |
| **Month** | Retired. The twelve-face calendar is no longer the run structure; five unused faces sit in `Locations/_Shelved/`. |
| **Day** | One unit of the hero's journey. In gameplay it equals a floor. See [[Day and Floor]]. |
| **Waystar** | The stone that fell when the Second Moon first appeared. Points toward the Far Place and returns the hero after death. See [[The Waystar]]. |
| **Path** | The road indicated by the Waystar. Nine locations. See [[The Path]]. |
| **Far Place** | The journey's end; three Act 3 doors approach it. See [[The Far Place]]. |
| **Starfold** | Act 3 location: the Inner Sky, demesne of the Magus. See [[Starfold]]. |
| **The Magus** | Stub as a person. Locked as the named deity: goblin tax, carnival tickets, Starfold boss. See [[The Magus]]. |
| **City** | What must be saved. Stake, home after death, Act 1 choice. See [[The City]]. |
| **Expedition / Run** | One attempt to walk the Path. A successful run = 3 locations / 45 days. See [[Run Structure]]. |
| **Return** | The Waystar's resurrection of the hero in the City after death. See [[Death and Return]]. |
