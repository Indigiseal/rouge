# Lore Glossary

| Term | Meaning |
|---|---|
| **Second Moon** | A magical sphere orbiting the ordinary moon. Source of the new calendar and threat waves. See [[The Second Moon]]. |
| **Turn / Orbit** | One full circuit of the Second Moon around the ordinary moon. Lasts 15 days and equals one month. |
| **Month** | A 15-day cycle of the new world. Each month-name defines a face of threat. See [[Months Index]]. |
| **Day** | One unit of the hero's journey. In gameplay it equals a floor. See [[Day and Floor]]. |
| **Waystar** | The stone that fell when the Second Moon first appeared. Points toward the Far Place and returns the hero after death. See [[The Waystar]]. |
| **Path** | The road indicated by the Waystar. See [[The Path]]. |
| **Far Place** | The journey's end; the place said to explain and possibly end the Second Moon's influence. See [[The Far Place]]. |
| **City** | What must be saved. Stake and emotional anchor. See [[The City]]. |
| **Expedition / Run** | One full attempt to walk the Path. A successful run = 3 months / 45 days. See [[Run Structure]]. |
| **Return** | The Waystar's resurrection of the hero at the start of the next month after death. See [[Death and Return]]. |
