# Thorn Ent

A fairy-tale wood-walker of the Briar March — small beside the century oaks, yet heavy enough to own a clearing. Trunk for a body, branch for arms, a face set in living timber; the bark is thick and hard, and living thorn-vine grips it like a second skin. Strike that hide and the spines answer through armor. It does not hurry. It does not need to.

Formerly drafted as "Briar Beast."
