# Road Sniper

A classic **fantasy long-shot** — crossbow, hunting bow, or wagon-roof archer. Not sci-fi. On the King's Mile he is the false kingdom's heavy bolt: most shots ordinary, some cruel.

Name keeps "Road" as setting; the readable type is **long-range archer / crossbowman**.
