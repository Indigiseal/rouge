# Music Box Chain

[[_Shared/Event Sequences|Event Sequence]]. Optional any-month lane (not required for the macro-plot). Tone leans [[08 Brassfair/Brassfair|Brassfair]] and [[10 Stormhatch/Stormhatch|Stormhatch]], but none of the beats are month-gated.

## Sequence

1. [[08 Brassfair/Events/The Broken Music Box|The Broken Music Box]] — opener
2. [[10 Stormhatch/Events/Monster Bird Nest|Monster Bird Nest]] — timed nest raid (cog / egg)
3. [[03 Tollroad/Events/Goblin Engineer|Goblin Engineer]] — repair (hidden if the box exploded)
4. [[10 Stormhatch/Events/The Egg Hatches|The Egg Hatches]] — companion (if egg taken)

## Design rule

These are global sequence events. Never soft-lock the lane because the calendar moved on. If the opener explodes, later rooms still appear, but cog and repair choices close.
