# Mirrorwane

The month of reflections, doubles, and wrong versions of the familiar. In this turn the world looks almost right — and is dangerous for exactly that reason.

## Theme

False familiarity — doubles, wells, and almost-correct rooms

## Location

### The Mirrorwane Halls

**The Mirrorwane Halls** is the signature place of this month.

Roster encountered here: [[Almost-You]], [[Glass Warden]], [[Shard Brute]], [[Reflection]], [[Well Spitter]].  
Boss: [[The False Path]].
