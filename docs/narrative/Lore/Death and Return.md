# Death and Return

In Evershift, dying on the road is not the end of the story. If the hero falls, the [[The Waystar|Waystar]] returns them to life **in the [[The City|City]]**, at the start of a new expedition.

This is not consequence-free immortality. The nine countries are still there. The Path did not wait. Someone else may have taken the Mile, or the caves, or the Inner Sky, and not come back.

## What this gives the story

- explains the roguelite loop without a calendar that advances for you;
- makes death a homecoming, not a skip;
- binds defeat to replayability (pick the three roads again);
- strengthens the sense that the hero is enduring a long, stubborn process of the world.

## Emotional meaning

Each return sounds less like "try again" and more like:

> You did not finish the road. The countries are still there. Choose.
