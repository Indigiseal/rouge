# Death and Return

In Evershift, dying on the road is not the end of the story. If the hero falls, the [[The Waystar|Waystar]] returns them to life **at the beginning of the next month**.

This is not consequence-free immortality. The world has already moved on. The sky is different. The face of the threat is different. The road is the same — but it now runs through a new month.

## What this gives the story

- explains the roguelite loop without abstraction;
- makes death part of the calendar;
- binds defeat to replayability;
- strengthens the sense that the hero is enduring a long, stubborn process of the world.

## Emotional meaning

Each return sounds less like "try again" and more like:

> You were too late for this month. Try to survive the next one.
